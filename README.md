# Expense Tracker

A simple personal finance web application built with HTML, CSS, and JavaScript.

## About the Project

Expense Tracker helps users manage their personal finances by tracking income, expenses, and balance in one place.

## Features

- **Dashboard:** View total income, total expenses, and current balance.
- **Expense Management:** Add and delete expense transactions.
- **Income Management:** Add income or edit the total income amount.
- **Balance Calculation:** Automatically calculate the remaining balance.
- **Statistics:** View expense summaries and basic statistics.
- **Transaction History:** Review recorded transactions.
- **Data Persistence:** Save income and expenses in the browser using LocalStorage.
- **Light and Dark Mode:** Switch between light and dark themes.

## Built With

- HTML5
- CSS3
- JavaScript
- Browser LocalStorage

## How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.

No additional installation is required.
